# Interface polish — November 12, 2026

Follow-up: the newer browser keys, magnitude cutoff, menu imagery and satellite cards are recorded in [the navigation update](MILKY_WAY_AND_NAVIGATION_2026-11-12.md) and [the optics/menu update](OPTICS_CLOUDS_CORONA_2026-11-12.md). The details below preserve the earlier milestone.


The startup laboratory, destination cards, Quantum library, star browser and object editor now share a dark observatory theme. Cyan identifies navigation and violet identifies Quantum. Existing native control names, keyboard focus, list navigation, text selection and application shortcuts remain available.

| Files | Change and reason |
| --- | --- |
| `src/UiTheme.h` | Shared background/panel/text/accent colors, DPI-scaled cached fonts, rounded buttons, clear hover/pressed/focus/disabled states, vector destination icons, subtle static orbital decoration, owner-drawn list rows and dark window captions. Avoids texture downloads, animated decoration and extra work in the 3D loop. Retains real native controls and accessible labels. |
| `src/AppMenu.h/.cpp` | Replaces bright stock cards with a quiet, spaced laboratory layout and short navigation copy. Hides the scene menu bar while the launcher is visible, then restores it on entry to a scene. Compact layouts reduce card density and omit secondary help where space is limited. Quantum uses a clear library/details split. |
| `src/ScenePanel.h/.cpp` | Uses matching list selection and heading fonts, adjusts panel spacing, and adds a compact local/world clock area plus a visible Play/Pause button. Keeps F3/F4/Shift+F4 and select-then-G travel. Browser/information panels still collapse to give space back to the 3D view. |
| `src/WindowManager.h/.cpp` | Routes list drawing and playback commands, updates the small clock area, and keeps input behavior. Renames the internal toast argument `small` to `compact` to avoid the Windows SDK's `small` macro. Includes Windows UI headers before the legacy global namespace import to prevent SDK type collisions. |
| `src/ObjectEditor.cpp` | Matches button, panel and caption styling without changing spin-slider/text validation or live editing. |
| `Render-Engine.vcxproj` | Lists the shared theme header for both backend projects. |
| `src/RenderChecks.cpp` | Captures the actual native control painting offscreen, verifies control bounds, tests the new Play/Pause button, and checks normal and compact startup layouts. Scene captures remain separate from UI captures. |
| README and screenshots | Show actual application captures and link the change records. Existing planet-view gallery images are retained. |

Native UI painting occurs only when a control needs redrawing. Fonts are cached and released at shutdown; temporary pens/brushes are restored and released after painting. No new timer or per-star CPU loop is introduced. The application's scene menus remain the native Windows menus so existing commands and shortcuts stay available.

The rendering checks remain numerical/behavioral regressions, supplemented by visual inspection of captures. They do not automatically establish visual perfection or accessibility compliance on every display/DPI setting.

Validation: native DX12 Debug passed 113 scene captures plus six normal/compact UI captures, with zero assertion failures and zero DX12 validation errors. OpenGL Debug passed 104 scene captures plus the same six UI captures. The new Play/Pause button was exercised. Main-menu, compact Quantum-library and live side-panel captures were visually inspected.

A focused `--ui-check <directory>` mode captures the six interface layouts without replaying the full astronomy suite. The parent handles native list-item measurement explicitly, and reopening the Quantum library scrolls its selected state into view. This fixes the initially invisible first selected row. The focused checks assert row size and visibility; the corrected compact view was inspected visually.
